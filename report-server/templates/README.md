# templates/

Đặt các file mẫu biểu thật vào đây (`.xlsx`, `.pptx`) khi có — dùng để nâng cấp
`lib/exportExcel.js` (hiện đang xuất bảng chung, chưa theo mẫu) và triển khai
`lib/exportPptx.js` (hiện đang throw lỗi "chưa triển khai") sang điền dữ liệu
vào đúng ô/placeholder của mẫu công ty, thay vì tự dựng file mới như hiện tại.
